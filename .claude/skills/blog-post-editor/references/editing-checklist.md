# Pre-Publish Checklist

Run this for any "publish pass" / "make it ready to publish" request. Report failures
to the user rather than silently fixing anything that involves a judgment call
(e.g., an unsupported claim). Mechanical items, just fix.

## Content

- [ ] The post argues/explains exactly one idea, stated within the first 100 words
- [ ] The hook works standing alone (would it stop a scroller?)
- [ ] Every factual claim has a source, a link, or a `<!-- SOURCE NEEDED -->` flag
- [ ] Numbers are consistent throughout (a "$19M proposal" in the intro isn't
      "$19 million USD" in the body and "19M" in the close — pick one style)
- [ ] No unexplained acronyms on first use (spell out, acronym in parentheses)
- [ ] The ending adds something (implication, CTA, question) — it doesn't just recap

## Structure

- [ ] A subheading every 150–300 words; heading levels nest correctly (no `##` → `####`)
- [ ] Headings alone convey the argument's skeleton
- [ ] No paragraph over 4 sentences
- [ ] Lists used where content is enumerable; no list with a single item

## Language

- [ ] Read the first sentence of every paragraph in sequence — does the post still flow?
- [ ] No filler phrases (see SKILL.md line-editing list)
- [ ] No AI-tell vocabulary or patterns (see SKILL.md list)
- [ ] Sentence length varies; no run of 3+ sentences of near-equal length
- [ ] Spelling/grammar pass done — including proper nouns (people, institutions,
      places spelled correctly and consistently)
- [ ] French posts: spacing before `: ; ! ?`, guillemets, sentence-case titles

## Metadata & formatting

- [ ] Title ≤60 chars, specific, contains main keyword
- [ ] Meta description 150–160 chars, written as a hook
- [ ] Slug: 3–5 lowercase hyphenated words
- [ ] Tags/categories set (3–6 tags; one category if the platform uses them)
- [ ] Every image has alt text; missing images have `<!-- IMAGE: … -->` placeholders
- [ ] All links have descriptive anchor text; no bare URLs in the body
- [ ] Links verified plausible (right domain, no obvious 404 patterns like doubled
      protocols); flag any you couldn't verify
- [ ] Date and language fields set in front matter

## Final

- [ ] Word count proportionate to the idea (no padding)
- [ ] The author's voice survived the edit — spot-check 3 characteristic sentences
      from the original draft; their flavor should still be findable
- [ ] Change summary written for the user
